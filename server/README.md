# SIGEDOC Backend

API del sistema SIGEDOC desarrollada con Node.js y Express.

---

## Requisitos

- Node.js
- npm

---

## Instalación

Clonar repositorio:

```bash
git clone https://github.com/TU_USUARIO/SIGEDOC.git
```

## Entrar al backend:

-  cd SIGEDOC/server
-  
## Instalar dependencias:

-  npm install
## Cambiar las variables de entorno de .env

-  PORT=3000
-  DB_HOST=localhost
-  DB_USER=root
-  DB_PASSWORD=password
-  DB_NAME=sigedoc

## Ejecutar el servidor

- npm run dev

## Servidor disponible en:
-  http://localhost:3000

## Tecnologías utilizadas
-  Node.js
-  Express
-  PostgreSQL
